Build, list and extract a 10,000-file ZIP

No performance claim. Each run creates all 10,000 paths, writes deterministic fixed-Huffman DEFLATE data and ZIP metadata, lists every central-directory entry, extracts ten frozen paths, and checks three exact SHA-256 outputs. Nothing is uploaded or stored.

The bounded mode runs the first 1,000 generated entries and stops after 10 seconds. It checks structure and selected contents but has no frozen output oracle. The full mode runs all 10,000 entries, checks the three frozen SHA-256 outputs, and stops after 30 seconds. Zip64 is forbidden because the full fixture has fewer than 65,535 entries and every size and offset is below 2³².
