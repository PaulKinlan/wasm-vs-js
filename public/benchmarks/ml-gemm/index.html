GEMM: 4 × 512×512 matrix products

Status: exploratory. This tab runs the controlled JS and linear-Wasm variants of a strict-f32 batched GEMM locally. No upload, no storage, no accepted corpus claim.

The worker generates deterministic input (xorshift32 seed 0x91e10da5), runs both variants in a fresh module worker, and validates every output element against the committed f64 reference and propagated f32 bounds.

    Multi-Language Comparison

    The same strict-f32 GEMM kernel (C = C0 + A·B, frozen i/j/k order, 128×128×128) written in JavaScript, C, C++, Rust, and Dart (WasmGC). All variants are bit-identical to the JS Math.fround oracle (test-verified); Dart/WasmGC emulates f32 with per-op fround since Dart has no f32 primitive — that overhead is real and disclosed. Sources: gemm.c · gemm.cpp · gemm.rs · gemm.dart.
