What it does

Adds, completes, filters, edits, and removes 100 todos through a full TodoMVC interaction — real DOM mutation, event dispatch, and virtual-dom reconciliation under realistic user input. Each run is the same frozen 150-command trace with the same fixture; the worker verifies the complete canonical DOM, accessible names and states, focus, selection, node reuse, and physical mutations before timing.

Why compare Wasm vs JS

DOM mutation, event dispatch, and virtual-dom reconciliation are where JavaScript engines and Wasm-backed implementations genuinely differ. The journey measures the full cost: state transitions, typed-command decode, and the physical DOM writes each target performs.
