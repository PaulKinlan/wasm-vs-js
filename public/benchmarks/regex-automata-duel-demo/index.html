Exact checks

Each run verifies the ordered match-tuple SHA-256 and exact code-point, pattern, match, capture, and boundary-crossing counters. A mismatch fails the run; it is never presented as a completed result.

Lifecycle

Start creates a fresh module worker, keeping fixture generation and scanning off the main thread. Cancel, completion, error, navigation, or the fixed 120-second timeout terminates that worker. Token checks ignore stale messages. Fixtures and results remain in memory.
