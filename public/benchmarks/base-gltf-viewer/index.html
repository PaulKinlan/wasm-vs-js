CPU reference

Fixed scope

The controlled renderer uses the model's base-color texture, opaque single-sided material, fixed camera, integer transforms, triangle culling, picking, and 600 retained CPU rasters. Metallic/roughness, tangent-space normal mapping, GPU upload, shader compilation, and driver output remain a separately unavailable product baseline; they do not become zero and do not enter this output.

The JavaScript target executes Google's Draco 1.5.7 asm.js decoder. The Wasm target executes the distinct Draco 1.5.7 linear-Wasm payload and an authored linear-Wasm frame engine. Both validate all 406 decoded vertices, 2,046 indices, 600 frame summaries, 12 picks, and six pixel buffers. The worker uploads nothing and stores nothing.
