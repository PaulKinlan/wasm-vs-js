What it does

Welds, orients, removes degenerate faces, and simplifies a dirty STL mesh to 50% using integer quantization and adjacency-map operations. Fixed work: 2,048 grid faces, 64 degenerate faces, and deliberately reversed winding; each target emits exactly 1,024 selected faces.

Why compare Wasm vs JS

Header-heavy binary parsing, contiguous Float32 coordinate quantization, and adjacency graph traversal are core bottlenecks in 3D printing and CAD pipelines.

Source & build provenance

  • Generated binary STL input
  • Linear-Wasm artifact
  • Build and source manifest
  • Correctness evidence
  • Authored C Wasm source

Scope & limitations

  • Deterministic project-generated 2,048-face grid under CC0-1.0.
  • No user uploads, file saving, or persistent result submission.
  • Fixed-work exact output check ensures 100% equivalence before timing.
