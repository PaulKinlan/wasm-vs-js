What it does

The fixed grammar parses headings, paragraphs, raw HTML, whole-line links, and figures. It then creates table-of-contents anchors, checks the URL and element allowlists, and serializes escaped canonical HTML. The Wasm option performs those stages in authored linear-memory code.
