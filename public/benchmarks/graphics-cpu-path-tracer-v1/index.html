CPU Ray-Tracing Path Tracer

Renders a deterministic 512×512 product preview at 64 samples per pixel using Monte Carlo integration, BSDF sampling, and ray-sphere/box intersection on the CPU.

Fixed work: 512×512 frame resolution, 64 rays per pixel, 4 ray bounces max depth. Both JavaScript and WebAssembly compute identical Monte Carlo pixel radiance arrays.

What it does

Traces 16.7 million light transport paths across 512×512 pixels with diffuse BSDF materials and point light sources.

Why compare Wasm vs JS

Tight math loops involving transcendental functions (`Math.sin`, `Math.cos`, `Math.sqrt`), vector dot/cross products, and random number generation test raw FPU pipeline throughput.

Source and build provenance

  • Executed workload engine
  • Worker harness
  • Engine build manifest

Scope & Limitations

  • Deterministic random seed initialization across both targets.
  • Runs in a dedicated background Web Worker to keep main thread fluid.
