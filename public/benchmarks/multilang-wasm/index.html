Source Comparison

Every implementation runs the identical algorithm: sum_u32 reduces 1,000 u32 integers; fft_butterfly runs a radix-2 Cooley–Tukey butterfly over 512 float pairs. The linear-memory variants (WAT, AssemblyScript, C, C++, Rust) operate on raw memory pointers. The Dart variant is a WasmGC module that consumes the same data zero-copy through dart:js_interop typed-array views. C/C++/AssemblyScript/ Rust/WAT use an f32 polynomial sin/cos (wasm32 has no hardware trig); JavaScript and Dart use f64 Math.sin/Math.cos — disclosed per variant.

Cold Start & Runtime Footprint

Managed WasmGC runtimes carry real cost: the Dart module is ~39.7 KB with 380 imports and its instantiation glue; the prebuilt Kotlin/Wasm document-edit module is ~37 KB with 216 imports. By contrast the linear-memory kernels are 94–2,479 bytes with zero imports. Measured cold-instantiation and per-workload warm timings are in the static report and the JSON report.
