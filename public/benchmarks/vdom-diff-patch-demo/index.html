Exact checks

Each run verifies the complete patch-tuple SHA-256 and exact node, depth, attribute, tag-replacement, reorder, insertion, and deletion counters. In addition, the main thread mounts real DOMHostAdapter elements into a hidden sandbox, applies the worker's patch list, and asserts that the resulting canonical browser DOM string and SHA-256 match the worker's expected output.

Lifecycle

Start creates a fresh module worker, keeping fixture generation and diffing off the main thread. Cancel, completion, error, navigation, or the fixed 120-second timeout terminates that worker. Token checks ignore stale messages.
