Dense MLP: 32 inputs × 512 width × 9 layers

Status: exploratory. This tab runs the controlled JS and linear-Wasm variants of a strict-f32 dense MLP locally. No upload, no storage, no accepted corpus claim.

The worker generates deterministic input (xorshift32 seed 0x5a17c0de), runs both variants in a fresh module worker, and validates every output element against the committed f64 reference and propagated f32 bounds across all layers.
