What it does

Scalar GEMM, convolution, and softmax over frozen row-major/NHWC tensors, in strict-f32 and INT8 variants. SIMD, compiler auto-vectorization, alternative layouts, and host ML APIs are excluded from this controlled scalar pair.

Why compare Wasm vs JS

Numeric kernel inner loops — multiply-accumulate, exponential approximation, normalization — are where a scalar linear-memory Wasm target genuinely differs from the JavaScript engine.

Correctness evidence

The benchmark loop above times both engines. This section runs one registered scalar kernel and validates its entire output — timing and correctness never mix.
