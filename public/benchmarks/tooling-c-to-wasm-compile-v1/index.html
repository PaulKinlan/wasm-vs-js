What it does

Compiles and links 20 small C programs to WebAssembly modules in the browser — lexing, parsing, type checking, code generation, and binary module emission.

Why compare Wasm vs JS

A self-hosted compiler is a stress test of parser hot paths, string handling, and binary emitter loops — the kind of compute a developer-tooling workload actually performs.

Exact scope

The admitted compiler revision preprocesses one fixture.h include, parses and typechecks a frozen signed-i32 expression grammar, emits and links a complete Wasm module, and runs its export. It is not presented as a general ISO C compiler.
