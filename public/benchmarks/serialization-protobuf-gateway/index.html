What it does

Decodes Protocol Buffer messages, filters records, and emits ProtoJSON responses — varint decoding, field-tag dispatch, and JSON serialization of nested message types.

Why compare Wasm vs JS

Wire decoding + JSON serialization is where a linear-memory Wasm target (fixed 32 MiB, no host serializer) genuinely differs from the JavaScript engine's own paths.

What is admitted

The frozen schema covers uint64, strings, booleans, double, enum, repeated strings, map<string,sint64>, bytes, oneof, int32, and float. The corpus exercises duplicate singular, map, and oneof fields; unknown wire types 0, 1, 2, and 5; defaults; values above JavaScript's safe integer range; non-finite numbers; multilingual UTF-8; base64; and JSON escaping. Unknown fields are counted and omitted from ProtoJSON.

The Wasm target performs wire decoding, filtering, duplicate and oneof resolution, map sorting, UTF-8 output construction, number formatting, JSON escaping, and base64 inside fixed 32 MiB linear memory. It does not call a JavaScript reducer or host JSON serializer.
