SQLite analytical notebook

No performance claim. This correctness route creates a fresh in-memory database, imports 4,192 generated rows in a frozen order, creates three indexes, and executes eight ordered SQL queries. It never uses OPFS, uploads, storage, or timing rankings.

The two targets are semantic product choices: the AlaSQL npm package is 4.17.3 while its embedded runtime reports 4.17.2 (build develop-f960d23a); the linear Wasm target is SQLite 3.53.0. Both execute the same SQL text and every returned value is checked against an independent command-line SQLite reference.

Fresh worker per run. Hard timeout: 120 seconds. Cancel terminates the worker.
