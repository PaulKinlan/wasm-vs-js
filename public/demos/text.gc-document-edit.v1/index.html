Implementation boundary

The JavaScript target owns a Map-backed object graph. The WasmGC target executes the same edit machine inside a Kotlin-generated WasmGC module using managed node objects, mutable child lists, and strings. The memory models intentionally differ and remain a semantic product choice. Portable runtime GC events and internal allocation totals are unavailable.

The generated fixture manifest, build manifest, and JavaScript correctness record are inspectable. Nothing is uploaded, persisted, or ranked.
