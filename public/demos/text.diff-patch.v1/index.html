No performance claim. This bounded demo runs one target in a worker and checks that its canonical script recreates the target. It does not upload or store the source or result.

What runs

Both targets intern UTF-8 lines, execute Myers O(ND), choose deletion before insertion on a tied frontier, encode the complete script, apply it, and compare every output line. The Wasm option fetches the authored linear-memory artifact.
