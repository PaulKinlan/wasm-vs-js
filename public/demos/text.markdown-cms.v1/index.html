Markdown CMS render pipeline

No performance claim. This bounded demo runs one target in a worker. It does not upload or store the source or result. Canonical HTML is shown as text and is never inserted into the page.

Controlled target

Source accepts at most 40,960 UTF-8 bytes. Raw HTML permits only attribute-free em and strong elements without nested markup. Links permit only https://example.test/ and https://docs.example.test/; figure sources permit only https://images.example.test/. The worker stops after 10 seconds.

What runs

The fixed grammar parses headings, paragraphs, whole-line links, figures, and raw HTML. It then creates table-of-contents anchors, checks the URL and element allowlists, and serializes escaped canonical HTML. The Wasm option performs those stages in authored linear-memory code.
