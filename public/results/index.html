What this shows

Individual benchmark run records from the local KV store, with workload, target, cache state, and correctness status.

What this does not show

Performance conclusions, timing comparisons, or competitive declarations. Those require the M1 pilot corpus with preregistered stopping rules and statistical analysis.

Data source

Runs are stored via POST /v1/runs in Deno KV. The explorer fetches from GET /v1/runs with URL hash-backed filters for shareable views.
