# Generated fixture rights

The `network.pcap-decode.v1` controlled fixture is generated entirely by
`fixture.ts`. It contains reserved documentation addresses, invented payloads,
and no captured network traffic or personal data.

The project dedicates the generated fixture bytes to the public domain under
CC0-1.0. Redistribution is permitted. No source packet capture, Wikipedia
capture, production capture, or GPL-linked parser is used.
